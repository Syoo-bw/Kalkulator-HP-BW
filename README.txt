Kalkulator HP Bloodwars by Syoo
===============================

Publikacja na darmowym hostingu

Najprościej – Netlify Drop:
1. Rozpakuj ZIP.
2. Wejdź na Netlify i użyj opcji ręcznego wdrożenia strony (drag & drop).
3. Przeciągnij cały folder zawierający index.html.
4. Po publikacji otrzymasz publiczny link, który możesz udostępnić innym.

GitHub Pages:
1. Utwórz nowe publiczne repozytorium na GitHubie.
2. Dodaj do niego index.html.
3. W Settings > Pages ustaw publikację z gałęzi main, katalog root (/).
4. GitHub wygeneruje publiczny adres strony.

Jak działa zapis danych
- Każdy użytkownik korzysta z własnego localStorage w swojej przeglądarce.
- Dane jednej osoby nie są widoczne dla innych i nie nadpisują ich wyników.
- Dane pozostają zapisane po zamknięciu strony i ponownym wejściu na nią na tym samym urządzeniu/przeglądarce.
- Przycisk „Przywróć wartości domyślne” czyści zapis dla tej strony.

Ważne
- Strona nie wymaga serwera, bazy danych ani PHP.
- Całe obliczenie odbywa się lokalnie w przeglądarce.
- Wynik końcowy HP jest zaokrąglany do pełnej liczby zgodnie z zasadami matematycznymi.
